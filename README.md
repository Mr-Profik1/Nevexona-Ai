# Nevexona AI Studio

Красивая клиентская AI-студия (чат + генерация фото + видео) на чистом HTML/JS.  
Работает полностью на **GitHub Pages** без бэкенда.

## Возможности

- Регистрация / вход (данные в `localStorage`)
- Чат с локальным ассистентом + поддержка Gemini API
- Генерация изображений через Gemini (`gemini-3.1-flash-image`)
- Генерация видео через Gemini Omni Flash (`gemini-omni-1.1-flash`)
- Демо-режим видео
- Галерея работ
- Админ-панель (лимиты, бан, экспорт/импорт пользователей, объявления)
- Адаптивный дизайн (мобильный + десктоп)

## Как задеплоить на GitHub Pages

1. Создай новый репозиторий на GitHub (например `nevexona-ai`).
2. Загрузи файл `index.html` в корень репозитория.
3. Перейди в **Settings → Pages**.
4. Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)`.
5. Сохрани. Через 1–2 минуты сайт будет доступен по адресу:
   ```
   https://<твой-username>.github.io/<имя-репозитория>/
   ```

## Первый вход как владелец

- Email: `admin@nevexona.ai`
- При первом входе задай любой пароль — он сохранится.

После входа зайди в **Настройки → API ключи** и вставь свой **Gemini API Key**  
(получить можно на [aistudio.google.com](https://aistudio.google.com)).

## Быстрый демо-вход

На экране авторизации есть кнопка **«Быстрый демо-вход»** — создаёт временного пользователя без пароля.

## Neon Chat (бесплатный чат на Ollama)

Файл `neon-chat.html` — отдельный чат в оранжевом неоне без платных API. Он работает с моделью, запущенной на вашем компьютере через [Ollama](https://ollama.com), и не использует ключи из `config.js`.

1. Установите Ollama и скачайте модель, например `ollama pull qwen2.5`.
2. Откройте `neon-chat.html` (локально или со страницы GitHub Pages: `.../neon-chat.html`).
3. Если открываете со страницы GitHub Pages, разрешите сайту доступ к Ollama:
   - Windows: переменная окружения `OLLAMA_ORIGINS=https://<твой-username>.github.io`, затем перезапустить Ollama.
   - Mac/Linux: `OLLAMA_ORIGINS=https://<твой-username>.github.io ollama serve`.
4. Адрес Ollama и системный промпт меняются в «Настройки» (по умолчанию `http://localhost:11434`).

### Голос и команды

- 🎤 — голосовой ввод (Chrome или Edge, нужен доступ к микрофону). Язык меняется в настройках (по умолчанию `ru-RU`).
- 🔊 — озвучка ответов.
- Команды (голосом или текстом), всё остальное уходит в модель:
  - `открой ютуб`, `открой github.com`
  - `найди рецепт борща`
  - `позвони +79991234567`, `смс +79991234567 привет` (открывается приложение, нажать «отправить» нужно самому)
  - `таймер на 5 минут`
  - `скопируй ответ`, `новый чат`

Браузер не может управлять самим компьютером или телефоном (программы, файлы, настройки), поэтому команды ограничены тем, что разрешено странице.

### Фото и видео

**Фото.** Кнопка «🖼 Генерация фото» в боковом меню. Два движка:
- Локально через [Stable Diffusion WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui) (или Forge): запустите его с флагами `--api --cors-allow-origins=*`, положите модель (например SD 1.5 для слабых видеокарт или SDXL для мощных) в папку `models/Stable-diffusion`. Адрес по умолчанию `http://127.0.0.1:7860`, меняется в «Настройки».
- Онлайн бесплатно через Pollinations: ничего ставить не нужно, но описание уходит на сторонний сервис, и его доступность не гарантирована.

**Видео.** Кнопка «🎬 Генерация видео». Чат отправляет задачу в ваш локальный [ComfyUI](https://github.com/comfyanonymous/ComfyUI), поэтому подойдёт любая видеомодель, которая в нём работает. Самые лёгкие бесплатные варианты: LTX-Video (2B) и Wan 2.1 T2V 1.3B (по заявлению авторов, около 8 ГБ видеопамяти; актуальные требования смотрите на страницах моделей).

Один раз настройте:
1. Запустите ComfyUI с флагом `--enable-cors-header "*"` (адрес по умолчанию `http://127.0.0.1:8188`).
2. В ComfyUI откройте шаблон видео (Workflow → Browse Templates, LTX-Video или Wan), он сам предложит скачать нужные файлы модели.
3. Включите Dev mode в настройках ComfyUI и выберите Save (API Format).
4. В чате: «🎬 Генерация видео» → «Настройка ComfyUI» → вставьте JSON. Описание подставится в положительный промпт автоматически, либо впишите в текст промпта метку из двойных фигурных скобок со словом `prompt`.

Генерация видео занимает от нескольких минут. Результат показывается в окне, ссылка для скачивания рядом.

Сами файлы моделей в репозиторий не кладутся: они весят гигабайты и скачиваются на ваш компьютер.

### Админ-панель

Кнопка «🛡 Админ-панель» в боковом меню. Вход: логин `mr-profik1` (ник GitHub, регистр не важен) и пароль владельца. В коде хранится только солёный хеш пароля (PBKDF2-SHA256), сам пароль в репозитории не лежит.

В панели: статистика, дневной лимит, объявление над чатом, режим техработ, сброс счётчика, экспорт и удаление чатов. Админ лимитом не ограничен. После 5 неверных попыток вход блокируется на минуту.

Чтобы сменить логин или пароль, сгенерируйте хеш и подставьте значения `ADMIN_USER`, `ADMIN_SALT`, `ADMIN_HASH` в `neon-chat.html`:

```
node -e "const c=require('crypto');const s='nvx-neon-'+c.randomBytes(8).toString('hex');console.log(s,c.pbkdf2Sync(process.argv[1],Buffer.from(s),200000,32,'sha256').toString('hex'))" 'НОВЫЙ_ПАРОЛЬ'
```

Важно: страница статическая, весь код открыт, а настройки лежат в браузере. Панель управляет только вашим браузером и не защитит данные от человека, который сам откроет код. Для настоящей защиты нужен сервер.

### Лимиты

В боковой панели показан счётчик сообщений за сегодня (по умолчанию 30 в день, сбрасывается в полночь). Лимит меняется в админ-панели, `0` — без лимита. Команды (открыть сайт, таймер и т. д.) в лимит не входят, считаются только ответы модели. Счётчик хранится в браузере, поэтому это удобное ограничение для себя, а не защита: очистка данных сайта его сбрасывает.

История чатов хранится только в браузере (`localStorage`).

## Важно

- Все данные (пользователи, лимиты, ключи) хранятся **только в браузере** посетителя.
- API-ключ Gemini виден только владельцу и хранится локально.
- На GitHub Pages нет серверной части — всё работает клиентски.
- Blob-изображения/видео из генерации живут до перезагрузки вкладки (это ограничение браузера).
